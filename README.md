# 保知通

面向互联网保险售后新人客服的知识学习与智能辅助平台。

## 项目背景

互联网保险产品、售后流程和业务规则更新频繁。新人客服需要阅读大量分散的产品资料、操作手册和业务公告，难以快速建立完整的知识框架。

本项目通过结构化知识库、RAG 问答、新知识通知和场景化测验，帮助新人客服快速掌握基础知识，并及时了解业务规则变化。

## 目标用户

- 新人客服
- 资深客服
- 知识管理员
- 客服主管

## 核心功能

1. 新人知识学习路径
2. 基于企业知识库的问答助手
3. 回答引用来源和知识版本
4. 新旧知识版本差异对比
5. 新知识发布与已读确认
6. 根据新知识自动生成测验
7. 学习进度和错题统计
8. 知识审核、发布和失效管理

## 首期业务范围

首期使用虚构的互联网医疗险产品，覆盖：

- 保险基础概念
- 保单查询
- 投保人及被保险人信息变更
- 续期缴费
- 犹豫期退保
- 正常退保
- 理赔申请
- 理赔材料补交
- 投诉与人工升级

## 项目原则

- 不使用真实客户个人信息
- 不使用原公司的内部资料
- 所有业务资料均来自公开信息或虚构数据
- AI 回答必须提供知识来源
- 无可靠来源时不允许编造答案
- 问答只使用当前有效版本的知识
