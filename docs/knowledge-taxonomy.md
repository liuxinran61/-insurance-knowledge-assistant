# 互联网保险售后客服知识分类体系

## 设计目标

本分类体系用于：

1. 帮助新人客服建立完整的保险售后知识框架。
2. 支持知识的分类、搜索和学习路径设计。
3. 支持 RAG 根据产品、场景和知识类型进行过滤。
4. 支持业务更新后定位受影响的知识和客服人员。

## K01 保险基础知识

### 知识点

- 投保人
- 被保险人
- 受益人
- 保险人
- 保险合同
- 保险责任
- 责任免除
- 保额与保费
- 等待期
- 犹豫期
- 宽限期
- 现金价值
