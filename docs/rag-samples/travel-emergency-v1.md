# 旅行险境外紧急援助指引（演示资料）

本资料为虚构测试规则。客户在境外发生突发疾病、意外受伤或证件遗失时，客服应优先确认客户所在国家或地区、联系方式和是否存在即时人身危险。

如需紧急医疗协助，应引导客户联系 24 小时援助热线，并建议在当地紧急情况下先拨打当地急救电话。客服不得以聊天消息替代紧急医疗建议。

证件遗失时，客服可提示客户联系当地警方和中国使领馆，并协助记录报案信息。是否属于保障责任、医疗费用是否可赔，必须由理赔专员依据有效条款确认。

跨时区场景下，援助热线可全天受理；非紧急的资料补交和理赔进度咨询按工作日处理。
