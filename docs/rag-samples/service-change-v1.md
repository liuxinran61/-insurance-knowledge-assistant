# 保单售后服务变更指引（演示资料）

> 本文件为“保知通”项目的虚构测试资料。

## 1. 联系方式变更

客户申请变更手机号或通讯地址时，客服应先完成身份核验，再引导客户在 App 的“保单服务—联系信息”中提交申请。

手机号变更在审核通过后即时生效；通讯地址变更在 **1 个工作日内** 生效。

## 2. 电子保单补发

客户可在 App 的“我的保单”中自行下载电子保单。无法下载时，客服可核验身份后发起补发申请，系统会在 **30 分钟内** 将下载链接发送至已核验手机号。

## 3. 犹豫期退保咨询

演示产品的犹豫期为保单生效后的 **15 个自然日**。客户在犹豫期内申请退保，客服应说明具体金额以系统核算结果和保单条款为准，不得自行承诺全额到账时间。

## 4. 转人工条件

以下情形必须转人工专员：

- 客户投诉或要求升级处理；
- 客户认为保单信息、扣费金额与约定不一致；
- 涉及退保金额、受益人变更或保单效力争议；
- 客户无法完成身份核验。
