# 道路救援服务指引（演示资料）

本资料为虚构测试规则。车辆因爆胎、电瓶亏电、无法启动或钥匙遗失无法开锁时，客户可申请道路救援。

客服登记时需要确认：车牌号、当前位置、联系电话、故障类型以及车辆是否位于高速公路或地下车库。

市区普通道路的救援服务目标到达时间为 **60 分钟内**；偏远地区、高速公路或极端天气可能延长，客服不得承诺精确到达时刻。

道路救援不包含事故责任认定、维修费用赔付和危险路段救援决策。客户位于高速公路或存在人身风险时，应优先提示其报警并转移至安全区域。
