# 客户投诉与升级处理指引（演示资料）

本资料为虚构测试规则。客户明确表示投诉、要求升级、质疑服务态度或要求监管投诉渠道时，客服应保持中性表达并创建投诉或升级工单。

记录内容应包括客户诉求、涉及保单或报案号、发生时间、已采取的处理动作和客户期望的回复方式。不得在工单中记录与处理无关的敏感个人信息。

客服可以说明“已登记并转交专员跟进”，但不得承诺投诉结论、补偿金额或具体回复日期。

如客户存在人身安全风险、激烈冲突或疑似欺诈线索，应按内部紧急流程立即升级，不在普通聊天中继续争辩。
