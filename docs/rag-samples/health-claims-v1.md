# 健康险住院理赔服务规则（演示资料）

本资料为虚构测试规则。客户申请住院医疗费用理赔时，应在出院后尽快提交资料。

常见材料包括：被保险人身份证明、住院病历或出院小结、费用总清单、医疗发票、医保结算单（如有）和银行卡信息。客服不得要求客户在聊天窗口发送完整银行卡号。

资料齐全后，演示产品的初步审核目标时效为 **5 个工作日**。如涉及既往症、责任认定或第三方先行赔付，需由理赔专员进一步核实。

客服只能说明材料和流程，不能解释诊断结论是否一定属于保障范围，也不能承诺赔付比例或赔付金额。
