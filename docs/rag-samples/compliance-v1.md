# 客服隐私与合规沟通规范（演示资料）

> 本文件为“保知通”项目的虚构测试资料。

## 1. 最小必要原则

客服仅可收集完成当前服务所必需的信息。不得在聊天窗口索取完整身份证号、银行卡号、短信验证码或支付密码。

## 2. 身份核验

涉及保单查询、联系方式变更、电子保单补发或理赔进度查询时，应按系统指引完成身份核验。核验失败时，不得披露保单详情，应转人工协助。

## 3. 话术边界

客服可以解释流程、材料和已公开规则；不得作出赔付承诺、收益承诺或超出有效规则版本的解释。

当知识库没有对应依据时，应回复“暂未检索到可确认的规则，已为您转交人工专员核实”，而不是猜测或编造答案。
