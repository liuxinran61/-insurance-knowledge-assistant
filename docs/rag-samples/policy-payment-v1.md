# 保费扣款失败与续期服务指引（演示资料）

本资料为虚构测试规则。客户反馈续期扣款失败时，客服应先核对保单状态、扣款日期和支付渠道状态，不得索取银行卡密码或短信验证码。

常见原因包括余额不足、银行卡状态异常、支付限额或授权失效。客户可在 App 的“续期缴费”页面重新支付，或按系统提示更换已核验的支付方式。

若客户认为扣款金额与约定不一致、出现重复扣款或已经缴费但保单状态未更新，必须转人工专员核实。客服不得自行确认退款时间或保单效力恢复时间。
