# 家财险水损报案与理赔材料指引（演示资料）

本资料为虚构测试规则。发生室内漏水、管道破裂或暴雨进水时，客户应先在确保人身安全的前提下采取止损措施，并尽快报案。

报案信息包括事故地址、发现时间、漏水原因初步描述、受损物品情况和现场照片或视频。

后续通常需要补充：保单信息、房屋使用或居住证明、维修报价或发票、受损物品清单以及第三方责任材料（如物业或邻居责任）。

客服不得指导客户自行拆改现场以获取理赔证明；涉及漏水责任归属争议时，应转交理赔专员处理。
