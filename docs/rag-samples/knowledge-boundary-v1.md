# 知识库问答拒答与转人工规范（演示资料）

本资料为虚构测试规则。当知识库没有足够依据、资料版本不明确或客户问题涉及个案赔付决定时，客服应明确说明“暂未检索到可确认的规则”，并转交人工专员核实。

以下问题不得由知识库问答直接给出确定结论：是否一定赔付、具体赔付金额、客户个案责任比例、保单是否必然有效、未来保费是否调整。

回答中应区分“流程说明”和“最终决定”：可以解释需要什么材料、下一步如何操作；最终责任认定、金额和条款适用必须以有效保单及人工审核结果为准。
