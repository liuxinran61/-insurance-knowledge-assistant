# 安心行车险理赔服务规则（演示资料）

> 本文件为“保知通”项目的虚构测试资料，不对应任何真实保险公司、产品或理赔承诺。

## 1. 事故报案时效

发生保险事故后，客户应在 **48 小时内** 通过官方 App、客服电话或合作门店报案。

如遇人身伤亡、车辆无法移动、与第三方发生争议等紧急情形，客服应先提示客户报警或联系急救服务，再协助完成报案登记。

## 2. 首次报案需要收集的信息

客服应引导客户提供：

1. 被保险人姓名与联系方式；
2. 车牌号和保单号；
3. 事故发生时间、地点和经过；
4. 是否涉及人员受伤、第三方车辆或财产损失；
5. 是否已报警，以及交警或事故认定书的取得情况。

## 3. 理赔材料清单

客户申请维修费用理赔时，通常需要提交：

- 被保险人身份证明；
- 驾驶证和行驶证；
- 保单信息；
- 事故证明、现场照片或视频；
- 维修清单与维修发票；
- 涉及第三方损失时的责任认定材料。

材料可通过 App 上传。客服不得要求客户在聊天窗口发送完整身份证号、银行卡号或保单照片原件。

## 4. 处理时效

资料齐全后，理赔专员会在 **3 个工作日内** 完成初步审核并反馈缺件或下一步安排。

若需现场查勘或补充责任认定，处理时效从补齐材料之日重新计算。客服应避免承诺具体赔付金额。

## 5. 常见边界说明

- 客服可以解释材料和流程，但不能判断是否一定赔付；
- 对责任比例、免责条款和损失金额有争议时，应转交理赔专员；
- 规则以保单条款及事故发生时有效的版本为准。
