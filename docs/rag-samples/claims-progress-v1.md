# 理赔进度查询与催办服务规范（演示资料）

本资料为虚构测试规则。客户查询理赔进度前，客服应先完成身份核验，并核对报案号或保单信息。

客服可以告知系统已展示的处理节点，例如“资料待补充”“审核中”或“已结案”，但不得擅自解释内部审核结论。

当案件超过系统显示的预计处理时间，客服可以发起催办记录，并告知客户会由理赔专员跟进。催办不等同于承诺具体结案时间。

客户要求修改事故经过、补充关键材料或对审核结论提出异议时，应转交理赔专员。
