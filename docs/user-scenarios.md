# 用户角色与业务场景

## 1. 用户角色

### R01 新人坐席

#### 背景

入职时间不超过三个月，对保险概念、产品条款和售后流程缺少系统认知。

#### 核心需求

- 按照学习路径掌握基础知识
- 快速查询当前有效的处理流程
- 通过场景练习检查学习效果
- 了解最近更新的业务知识
- 遇到高风险问题时知道如何升级

#### 主要困难

- 不理解保险专业术语
- 不知道知识分布在哪份文档
- 容易混淆不同产品的处理规则
- 容易使用过期流程
- 难以判断何时需要升级

### R02 进阶坐席

按照以下结构自行补充：

- 背景
入职时间超过三个月 对保险问题比较了解 可以回答高风险问题
- 核心需求
了解最近更新的业务知识
- 快速查询当前有效的处理流程
- 遇到高风险的问题知道怎么回答和安抚用户

- 主要困难
及时更新最新消息
及时响应高风险用户 有时效性
及时向上反馈坐席需求

### R03 知识管理员

按照以下结构自行补充：

- 背景
是知识库的知识体系来源 及时更新最新的消息和知识问题
- 核心需求
有最新的政府文件 来解答问题 确保提供的文件的合法性和时效性
- 主要困难
及时 合法 文件分类 知识库运维

### R04 坐席管理员

按照以下结构自行补充：

- 背景
权限维护 给不同等级的坐席有文件权限和知识库功能的区分
及时更新坐席表 和等级表

- 核心需求
管理坐席的知识库基本操作
- 主要困难
权限运维
